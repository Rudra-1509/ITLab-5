# Multiplayer Game Platform (College Software Engineering Project)

This repository contains the multiplayer gaming platform system.
The backend service is located in the [`backend`](file:///./backend) directory.

## Quick Start
```bash
# Enter backend
cd backend

# Install dependencies
npm install

# Run development server
npm run dev

# Run automated end-to-end verification
npm test
```

For complete API documentation, Socket.IO contracts, and LAN multiplayer setup instructions, refer to [`backend/README.md`](file:///./backend/README.md).
